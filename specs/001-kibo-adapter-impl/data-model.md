# Data Model: Kibo ↔ COF Entity Mappings

**Feature**: 001-kibo-adapter-impl | **Date**: 2026-02-04

## Entity Overview

| COF Entity | Kibo Entity | Relationship |
|------------|-------------|--------------|
| `Order` | `KiboOrder` | 1:1 |
| `Fulfillment` | `KiboShipment` | 1:1 |
| `InventoryItem` | `KiboInventory` | 1:1 |
| `Product` | `KiboProduct` | 1:1 |
| `ProductVariant` | `KiboProductVariation` | 1:1 |
| `Customer` | `KiboCustomerAccount` | 1:1 |
| `Return` | `KiboReturn` | 1:1 |

## Order Entity

### COF Order → Kibo Order (Create)

```typescript
interface COFOrder {
  id?: string;                    // Generated by Kibo
  externalId: string;             // → externalId
  status: OrderStatus;            // → (mapped)
  customer: CustomerRef;          // → customerAccountId + email
  shippingAddress: Address;       // → fulfillmentInfo.fulfillmentContact
  billingAddress: Address;        // → billingInfo.billingContact
  items: OrderItem[];             // → items[]
  totals: OrderTotals;            // → subtotal, shippingTotal, taxTotal, total
  metadata?: Record<string, unknown>;  // → attributes[]
}
```

### Kibo Order → COF Order (Query)

| Kibo Field | COF Field | Transformation |
|------------|-----------|----------------|
| `id` | `id` | Direct |
| `orderNumber` | `orderNumber` | Direct |
| `status` | `status` | `mapKiboOrderStatus()` |
| `submittedDate` | `createdAt` | ISO 8601 parse |
| `customerAccountId` | `customer.id` | String coercion |
| `email` | `customer.email` | Direct |
| `fulfillmentInfo.fulfillmentContact` | `shippingAddress` | `mapKiboAddress()` |
| `items[]` | `items[]` | `mapKiboOrderItem()` |
| `subtotal` | `totals.subtotal` | Direct |
| `shippingTotal` | `totals.shipping` | Direct |
| `taxTotal` | `totals.tax` | Direct |
| `total` | `totals.total` | Direct |

### Status Mapping

## Common Types

### Address Mapping

```typescript
// Kibo Contact → COF Address
function mapKiboAddress(contact: KiboContact): Address {
  return {
    line1: contact.address.address1,
    line2: contact.address.address2,
    city: contact.address.cityOrTown,
    state: contact.address.stateOrProvince,
    postalCode: contact.address.postalOrZipCode,
    country: contact.address.countryCode,
    name: `${contact.firstName} ${contact.lastName}`,
    phone: contact.phoneNumbers?.home,
  };
}
```

### ID Coercion

Kibo uses numeric IDs internally but string IDs externally. All ID fields should be coerced to strings for COF compatibility:

```typescript
const customerId = String(kiboCustomer.id);  // number → string
```
